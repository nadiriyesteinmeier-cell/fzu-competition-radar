# 安全边界

- 浏览器永远不能读取 `OPENAI_API_KEY`。
- 日志只记录时间、状态码和错误代码，不记录摘要正文、密钥或完整订单对象。
- 商品价格由 `/api/products` 返回，创建订单时重新从服务端商品表取价。
- 游客订单继续按随机 `clientId` 隔离；登录订单按服务端账户 ID 隔离，Bearer 会话令牌只以 SHA-256 摘要保存在服务端。
- 密码使用 Node.js `scrypt` 和独立随机盐哈希，服务端不保存明文密码；连续登录失败会触发短期限流。
- 修改密码会撤销账号的全部旧会话；删除账号必须再次验证密码，并同步删除账号会话与账号订单。
- 邮箱验证令牌有效期 30 分钟，密码重置令牌有效期 15 分钟；令牌只以 SHA-256 摘要落盘、同类新令牌会替换旧令牌，并且成功使用后立即删除。
- 找回密码接口对已注册和未注册邮箱返回相同结果；邮件申请按邮箱或账号限流。重置密码会撤销全部旧会话。
- 邮箱验证只证明邮箱控制权，不会改变院校“平台未认证”状态。
- `EMAIL_EXPOSE_PREVIEW` 只能用于隔离的本地测试，生产环境必须关闭；邮件服务密钥只能保存在部署平台的服务端变量中。
- Web 内测令牌保存在浏览器本地存储，因此在真实收费前仍需补充更严格的 CSP、安全审计和令牌设备管理；微信小程序阶段改用服务端校验的 OpenID 会话。
- 未支付订单调用生成接口返回 `402 payment_required`。
- 生成失败后订单恢复为 `paid`，用户可以重试，不重复要求支付。
- 相同论文、服务和摘要命中缓存时不再次调用模型。
- 容器部署默认关闭模拟支付；不要在生产环境覆盖为 `true`。
- 容器入口只在启动时以 root 修正持久化卷权限，随后通过 `su-exec` 降权为 `node` 运行 API。
