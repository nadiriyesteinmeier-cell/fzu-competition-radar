# 安全边界

- 浏览器永远不能读取 `OPENAI_API_KEY`。
- 日志只记录时间、状态码和错误代码，不记录摘要正文、密钥或完整订单对象。
- 商品价格由 `/api/products` 返回，创建订单时重新从服务端商品表取价。
- 只有订单所属 `clientId` 可以查询、支付或生成；正式版必须升级为可信登录身份。
- 未支付订单调用生成接口返回 `402 payment_required`。
- 生成失败后订单恢复为 `paid`，用户可以重试，不重复要求支付。
- 相同论文、服务和摘要命中缓存时不再次调用模型。
- 容器部署默认关闭模拟支付；不要在生产环境覆盖为 `true`。
