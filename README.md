# 福大竞赛雷达

面向福州大学学生的竞赛时间信息验证版。第一版为响应式 Web/PWA：无需注册，可筛选、收藏，并把关键节点导出为 `.ics` 日历文件。

## 本地预览

直接打开 `index.html` 可以使用主要功能。要测试安装和离线访问，请在此目录启动任意静态文件服务器，通过 `http://localhost` 访问。

## 数据维护

赛事数据位于 `data/events.js`。每条记录必须包含公开原文、核验日期和明确的时间节点；全国截止与校内截止不得混写。

## 当前边界

- 不代理官方报名
- 不收集账号、学号或参赛作品
- 不自动生成参赛作品
- 不是福州大学或赛事主办方的官方平台
